# Café Bistro

Premium café, restaurant and boutique-stay website built from scratch with React, TypeScript, Vite and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Current phase

- Responsive premium light-theme frontend
- Hero, offerings, menu, story, gallery, events and contact sections
- Mobile navigation
- Menu cart counter UI
- Table-booking modal UI
- Ready for Firebase Auth, Firestore and Storage
